# Local development on Python 3.14 only. Never deployed.
#
# Four of the production pins have no cp314 wheel and cannot be built without a
# C compiler (numpy, asyncpg, greenlet) or a Rust toolchain plus the MSVC linker
# (pydantic-core, via pydantic). They are given floors here so pip can resolve to
# a version that ships a 3.14 wheel.
#
# Everything that CAN be pinned is still pinned, including starlette. Do not
# relax fastapi or starlette here either: starlette 1.x moves the get_db()
# teardown commit to after the response is sent, which breaks the session state
# machine intermittently and is extremely confusing to debug. That failure was
# originally introduced by loosening exactly these two lines.
#
# Deployment installs requirements.txt, not this file. If you change a version
# here, check whether requirements.txt needs the same change.
#
#   pip install -r requirements-py314.txt

# --- pinned, wheels exist on 3.14 ---
